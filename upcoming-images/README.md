# Upcoming amiibo images

Public image hosting for Amiibo Vault (Android + iOS). The Android repo stays private; this folder lives on the public **amiibo-vault-ios** repo so GitHub raw URLs work worldwide.

## File names

| File | Figure |
|------|--------|
| `sword-kirby-dragoon.png` | Sword Kirby & Dragoon |
| `noir-dedede-hydra.png` | Noir Dedede & Hydra |
| `samus-metroid-ravenous.png` | Samus |
| `chozo-statue-metroid-ravenous.png` | Chozo Statue |
| `samus-metroid-suit-metroid-ravenous.png` | Samus (Metroid Suit) |
| `young-link-ocarina-of-time.png` | Young Link |
| `young-zelda-ocarina-of-time.png` | Young Zelda |

## URL format

```
https://raw.githubusercontent.com/AleksaaDj/amiibo-vault-ios/main/upcoming-images/<filename>
```

Referenced from Firebase RTDB `/upcoming/items` and Android bundled `upcoming_amiibo.json`.
